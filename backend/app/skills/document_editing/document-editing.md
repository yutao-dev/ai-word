# 文档编辑 Skill

## 领域知识

文档编辑是指对文档内容进行修改、组织和优化的过程，包括但不限于：

### 常见文档编辑任务

1. **内容添加**：在文档的特定位置添加新内容
2. **内容修改**：修改现有内容的格式、结构或文字
3. **内容删除**：删除不需要的内容
4. **结构调整**：调整文档的章节顺序和层次结构
5. **格式优化**：优化文档的格式和排版

### 文档结构知识

- **标题层次**：使用不同级别的标题（如 #、##、###）来组织内容
- **段落结构**：合理分段，每个段落表达一个完整的思想
- **列表使用**：使用有序列表和无序列表来组织信息
- **引用格式**：正确使用引用块来突出重要信息

## 最佳实践

### 内容添加

- **明确位置**：使用 `insertEnd`、`insertAt` 或 `insertAfterHeading` 明确指定插入位置
- **内容质量**：确保添加的内容与文档整体风格一致，信息准确
- **上下文关联**：添加内容时考虑与前后文的逻辑关系

### 内容修改

- **精准定位**：使用 `searchInDocument` 或 `getSectionByHeading` 精确定位需要修改的内容
- **最小修改**：尽量只修改必要的部分，保持文档的整体结构
- **一致性**：确保修改后的内容与文档其他部分保持一致

### 结构调整

- **整体规划**：在调整结构前，先使用 `getDocumentOutline` 了解文档的整体结构
- **逻辑顺序**：调整章节顺序时，确保逻辑上的连贯性
- **引用更新**：如果调整了章节位置，确保相关引用也得到更新

## 常见场景

### 场景 1：在文档末尾添加内容

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `insertEnd` 在文档末尾添加内容
4. 验证添加是否成功

### 场景 2：修改指定章节内容

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `getSectionByHeading` 定位目标章节
4. 使用 `findAndReplace` 或 `updateDocumentContent` 修改内容
5. 验证修改是否成功

### 场景 3：调整文档结构

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `getDocumentOutline` 了解文档结构
4. 使用 `moveSection` 调整章节位置
5. 验证调整是否成功

## 提示词模板

### 添加内容

```
请在文档 {document_id} 的 {位置} 添加以下内容：
{内容}
```

### 修改内容

```
请修改文档 {document_id} 中的 {目标内容} 为：
{新内容}
```

### 调整结构

```
请调整文档 {document_id} 的结构，将 {源章节} 移动到 {目标章节} 的 {位置}。
```
