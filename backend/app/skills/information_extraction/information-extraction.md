# 信息提取 Skill

## 领域知识

信息提取是指从文档中提取特定信息的过程，包括但不限于：

### 常见信息提取任务

1. **摘要生成**：提取文档的主要内容，生成摘要
2. **关键词提取**：从文档中提取重要的关键词
3. **实体识别**：识别文档中的实体（如人物、组织、地点等）
4. **信息分类**：将文档内容分类到不同的类别
5. **数据提取**：从文档中提取特定的数据信息

### 信息提取技术

- **文本分析**：分析文本的语法和语义结构
- **模式匹配**：使用正则表达式或规则匹配特定模式
- **自然语言处理**：利用 NLP 技术理解文本内容
- **机器学习**：使用机器学习模型识别和提取信息

## 最佳实践

### 摘要生成

- **抓住重点**：提取文档的核心观点和主要信息
- **保持连贯**：生成的摘要应该逻辑连贯，易于理解
- **控制长度**：根据需求控制摘要的长度
- **忠实原文**：摘要应该忠实反映原文的内容和观点

### 关键词提取

- **相关性**：提取与文档主题相关的关键词
- **多样性**：提取不同类型的关键词，包括名词、动词等
- **代表性**：选择能够代表文档内容的关键词
- **数量适中**：提取适量的关键词，不宜过多或过少

### 实体识别

- **准确性**：准确识别文档中的实体
- **完整性**：识别文档中的所有相关实体
- **分类正确**：正确分类识别出的实体
- **上下文理解**：结合上下文理解实体的含义

## 常见场景

### 场景 1：生成文档摘要

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `extractKeyInfo` 提取摘要
4. 验证提取是否成功

### 场景 2：提取文档关键词

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `extractKeyInfo` 提取关键词
4. 验证提取是否成功

### 场景 3：识别文档中的实体

**步骤**：
1. 使用 `getAllDocument` 获取文档列表
2. 使用 `getDocumentById` 获取目标文档内容
3. 使用 `extractKeyInfo` 提取实体
4. 验证提取是否成功

## 提示词模板

```

```

### 提取关键词

```
请从文档 {document_id} 中提取 {数量} 个关键词。
```

### 识别实体

```
请从文档 {document_id} 中识别出所有的 {实体类型}。
```
