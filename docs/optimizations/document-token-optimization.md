# AI 工作流 Token 消耗优化方案

## 1. 项目背景

当前 AI 工作流在执行多轮操作时，存在 Token 消耗过高的问题。主要原因是每次迭代都会将完整的文档内容作为上下文发送给大模型，导致输入 Token 快速累积，特别是在处理长文档时。

## 2. 优化目标

- **减少 Token 消耗**：通过优化策略，减少 50% 以上的输入 Token 消耗
- **保持功能完整性**：确保优化后系统功能不受影响
- **提高响应速度**：减少输入 Token 后，模型响应速度会相应提高
- **降低 API 调用成本**：Token 消耗减少直接降低 API 调用成本

## 3. 优化策略

### 3.1 文档引用策略

**原理**：
- 首轮发送完整文档内容，让模型建立对文档的理解
- 后续轮次只发送文档 ID 和必要的修改信息，而不是完整内容
- 系统提示词中明确告知模型可以通过文档 ID 引用之前的内容

**实施步骤**：
1. 修改 `build_context_message` 函数，实现首轮发送完整文档，后续轮次发送文档引用
2. 更新系统提示词，明确告知模型可以通过文档 ID 引用之前的内容
3. 测试不同文档长度下的优化效果

**预期效果**：
- 首轮 Token 消耗不变，后续轮次 Token 消耗减少 80% 以上

### 3.2 增量更新策略

**原理**：
- 记录文档的修改历史，跟踪每次操作对文档的改变
- 后续轮次只发送与当前操作相关的部分内容
- 避免重复传输未变化的内容，只传输新增或修改的部分

**实施步骤**：
1. 实现文档修改跟踪机制，记录每次操作的修改内容
2. 修改 `build_context_message` 函数，实现增量更新
3. 测试文档修改频繁场景下的优化效果 

**预期效果**：
- 文档修改时 Token 消耗减少 60% 以上

### 3.3 上下文管理策略

**原理**：
- 限制历史对话长度，只保留最近几轮的对话
- 自动识别并移除重复的文档内容
- 聚焦当前任务，只保留与当前任务相关的信息

**实施步骤**：
1. 修改消息构建逻辑，限制历史对话长度
2. 实现重复内容检测和移除功能
3. 测试多轮对话场景下的优化效果

**预期效果**：
- 多轮对话时 Token 消耗减少 50% 以上

### 3.4 函数调用优化

**原理**：
- 引导模型使用函数调用来获取文档信息
- 提供更精确的函数参数，减少模型需要的上下文
- 要求模型返回结构化的操作结果，便于后续处理

**实施步骤**：
1. 优化系统提示词，引导模型使用函数调用
2. 改进函数接口设计，提供更精确的参数
3. 测试函数调用场景下的优化效果

**预期效果**：
- 函数调用场景下 Token 消耗减少 70% 以上

2. **`backend/app/services/skill/skill_service.py`**：

### 4.2 关键代码修改

**1. 文档引用实现**：
```python
def build_context_message(document_id, docs, iteration=1):
    if iteration == 1:
        # 首轮发送完整文档
        return build_full_context(document_id, docs)
    else:
        # 后续轮次发送文档引用
        return f"文档 ID: {document_id} (完整内容已在首轮提供)"
```

**2. 增量更新实现**：
```python
def build_incremental_context(document_id, docs, last_modification):
    # 只发送与当前操作相关的部分内容
    if last_modification:
        return f"文档 ID: {document_id}\n最新修改: {last_modification}"
    return f"文档 ID: {document_id}"
```

**3. 上下文管理实现**：
```python
def manage_context(messages, max_history=3):
    # 只保留最近几轮的对话
    if len(messages) > max_history * 2:  # 每轮包含用户和助手消息
        messages = messages[-max_history * 2:]
    return messages
```

3. **性能波动**：在某些场景下，优化可能导致性能下降
